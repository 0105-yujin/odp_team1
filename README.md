# odp_team1 - 캠퍼스 센서 수집 앱

캠퍼스에 설치된 고정 BLE 센서(`opensrc1` ~ `opensrc5`)의 온도/습도/AQI/TVOC/eCO2 값을 스캔하여,
휴대폰의 실제 GPS 위치와 함께 서버로 업로드하는 안드로이드 앱입니다.

## 1. 사전 준비

- 안드로이드 기기 (BLE, GPS 지원)
- 블루투스 켜짐
- 위치 서비스(GPS) 켜짐
- 인터넷 연결 (서버 업로드용)

## 2. 빌드 및 설치

Android Studio에서 프로젝트를 열고 Gradle Sync 후 실행하거나, 터미널에서:

```bash
./gradlew assembleDebug
```

생성된 APK(`app/build/outputs/apk/debug/`)를 기기에 설치합니다.

## 3. 최초 실행 시 권한 허용

앱 실행 시 아래 권한 요청 다이얼로그가 뜹니다. **모두 허용**해야 정상 동작합니다.

- 블루투스 스캔 / 연결 (Android 12 이상)
- 위치(정밀 위치, `ACCESS_FINE_LOCATION`)

권한을 거부하면 "블루투스/위치 권한이 없으면 스캔할 수 없습니다" 토스트가 뜨고 스캔/위치 업데이트가 시작되지 않습니다.
설정 > 앱 > 권한에서 나중에 허용해도 앱을 재실행하면 정상 동작합니다.

## 4. 화면 구성 및 사용법

| 버튼 | 동작 |
|---|---|
| 스캔 시작 | BLE 스캔을 시작합니다. 주변 광고를 모두 수신하되, 코드 내부에서 `opensrc1`~`opensrc5` 기기명만 걸러냅니다. |
| 스캔 중지 | BLE 스캔을 멈춥니다. |
| 저장 | 그동안 수신된 모든 센서값을 기기 내부 CSV(`ble_data.csv`)에 저장하고 버퍼를 비웁니다. |
| 전송 | 가장 마지막으로 수신한 센서 1건을 서버로 즉시(수동) 재전송합니다. |

### 동작 순서 (정상 케이스)

1. 앱 실행 → 권한 허용
2. "스캔 시작" 터치
3. 실외(또는 GPS가 잡히는 곳)로 이동 → 몇 초 내 위치 fix 수신
4. 캠퍼스 센서(`opensrc1`~`opensrc5`) 근처에 있으면 로그 창에 다음이 순서대로 출력됨:
   - `[수신] 이름: opensrcN, MAC: ..., RSSI: ...` + 파싱된 센서값
   - `[전송 시작] opensrcN (RSSI ...)`
   - `[서버 응답: 정상] ...` 또는 `[서버 응답: 범위 초과] ...`
5. 같은 센서는 **10초에 한 번씩만** 자동 업로드됩니다(연속 중복 전송 방지).
6. 필요 시 "저장" 버튼으로 CSV 백업, "전송" 버튼으로 마지막 값 수동 재전송.

## 5. 로그 메시지 안내

| 로그 | 의미 |
|---|---|
| `[무효] RSSI 0` | RSSI 값이 0으로 수신됨 (비정상 신호로 간주, 전송 안 함) |
| `[위치 미수신] 야외에서 잠시 대기` | 아직 GPS 위치를 못 받아서 전송을 보류함. 실외로 이동하거나 잠시 대기 |
| `[서버 응답: 정상]` | 서버가 값을 정상적으로 수신 |
| `[서버 응답: 범위 초과]` | 서버가 값을 범위 밖(비정상)으로 판단 |
| `[서버 응답 오류] HTTP ...` | 서버가 에러 응답(4xx 등)을 반환 |
| `[전송 실패]` | 네트워크 오류 등으로 요청 자체가 실패 |

## 6. 문제 해결(트러블슈팅)

- **로그에 아무것도 안 뜬다**: 센서가 광고하는 실제 기기명이 `opensrc1`~`opensrc5`와 정확히 일치하는지 확인하세요(대소문자/공백 포함 한 글자라도 다르면 무시됩니다). `MainActivity.java`의 `TARGET_NAMES` 참고.
- **"[위치 미수신]"이 계속 뜬다**: 위치 권한이 허용되어 있는지, GPS/위치 서비스가 켜져 있는지, 실내가 아닌지 확인하세요.
- **블루투스가 꺼져 있다는 토스트**: 기기 블루투스를 켜고 "스캔 시작"을 다시 누르세요.

## 7. 설정값 (MainActivity.java 상단)

| 상수 | 설명 |
|---|---|
| `TEAM_NO`, `TEAM_KEY`, `SENSOR_NAME` | 팀 식별 정보 (서버 전송 시 사용) |
| `TARGET_NAMES` | 수집 대상 센서 기기명 목록 |
| `UPLOAD_INTERVAL_MS` | 센서별 업로드 최소 간격(기본 10초) |
| `AUTO_UPLOAD` | `false`로 바꾸면 자동 업로드를 끄고 수동 전송만 사용 |
